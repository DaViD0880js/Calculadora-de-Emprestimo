# Calculadora de Empréstimo

Sistema simples desenvolvido em **Java** para realizar o cálculo do valor final de um empréstimo por meio do terminal.

## 📋 Sobre o projeto

O programa permite informar o **valor do empréstimo**, a **taxa mensal de juros** e o **prazo para pagamento**. A partir dessas informações, o sistema realiza o cálculo e apresenta o valor final em uma tabela organizada que mostra valor de juros, amortização e saldo devedor **em cada mês**.

O projeto foi desenvolvido com foco no aprendizado dos conceitos básicos de programação em Java e na aplicação de cálculos matemáticos em um programa executado pelo terminal.

## ⚙️ Funcionamento

O sistema segue basicamente as seguintes etapas:

1. Solicita ao usuário o valor do empréstimo.
2. Solicita a taxa mensal de juros.
3. Solicita o prazo de pagamento.
4. Realiza o cálculo dos juros, amortização e saldo devedor.
5. Exibe no terminal o valor final do empréstimo.

### Exemplo

```text
Valor do empréstimo: R$ 1000
Taxa mensal: 5%
Prazo: 12 meses

```

## 🎯 Objetivo

O objetivo deste projeto é desenvolver uma aplicação simples para cálculo de empréstimos, praticando conceitos fundamentais da linguagem Java, como:

- Entrada de dados;
- Variáveis;
- Operadores matemáticos;
- Cálculos com porcentagem;
- Estruturas básicas de programação;
- Interação com o usuário pelo terminal.
